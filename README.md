# chang-yoon

기계공학을 바탕으로 설계·해석, 로보틱스·제어·자동화 분야의 프로젝트와 활동을 정리합니다.

프로젝트의 목표부터 문제 해결 과정, 검증 결과까지 기록하고, 팀 프로젝트에서는 제가 맡은 역할과 기여를 구분해 소개합니다.

## 대표 프로젝트

### [L.E.O.N.A. — 태양광 패널 선택 세척 드론](https://github.com/chang-yoon/chang-yoon/blob/main/projects/autonomous-cleaning-drone.md)

Team DA-DAKA의 AI 비전 기반 드론 프로젝트입니다. 패널·오염 인식을 자율비행과 선택 분사에 연결했습니다.

**종합설계경진대회 은상 수상.** 한이음 결과를 기다리고 있으며, 프로젝트를 개선하여 WE-MEET에 참가할 예정입니다.

### [ANSYS Fluent 기반 수직축 풍력터빈 익형 비교](https://github.com/chang-yoon/chang-yoon/blob/main/projects/ansys-vawt.md)

2026년 1학기 기계공학특수연구의 4인 팀 프로젝트입니다. NACA 익형 3종을 대상으로 회전 유동을 해석하고 MODDE 분석과 결과 비교를 거쳐 발표 설계안으로 NACA 0015를 선정했습니다. 모델링부터 분석·발표까지 팀원들과 공동 수행했습니다.

### [센서·MQTT·Node-RED 기반 스마트팩토리 IoT 실습](https://github.com/chang-yoon/chang-yoon/blob/main/projects/smart-factory-iot.md)

센서 데이터 표시와 팬 원격 제어에서 시작해, 마스크 영상분류·온도 조건을 결합한 상태 판정으로 확장한 수업 실습입니다. 개인과제 2개와 6인 팀과제 4개의 수행 내용을 구분해 정리했습니다.

다른 프로젝트와 활동 자료도 정리하고 있습니다. 내용과 공개 범위를 확인한 기록부터 추가합니다.

## 기록 방식

- **역할:** 팀이 수행한 일과 제가 직접 수행한 일을 구분합니다.
- **과정:** 문제를 발견한 근거, 검토한 대안과 선택 이유를 설명합니다.
- **결과:** 측정 조건과 근거를 함께 제시하고, 검증하지 못한 범위도 기록합니다.
