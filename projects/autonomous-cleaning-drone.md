# L.E.O.N.A. — AI 비전 기반 태양광 패널 선택 세척 드론

**팀 프로젝트 · Team DA-DAKA(다닦아)**

태양광 패널의 위치와 오염을 영상으로 인식하고, 방문 경로 생성과 접근·정렬·선택 분사를 연결하는 프로젝트입니다. 사람이 접근하기 어려운 패널의 유지관리를 자동화하는 것을 목표로 개발했습니다.

## 시스템 구성

| 구성 | 역할 |
| --- | --- |
| Raspberry Pi 5 / ROS 2 | 센서와 추론 결과 활용, 위치·경로 계산, 임무 순서 관리 |
| NVIDIA GPU 노트북 | Panel V4 패널 검출, Dirt V3 오염영역 분할 |
| MAVROS / Pixhawk 4 / PX4 | 임무 명령과 비행 제어 연결, 기체 자세·모터·분사 출력 제어 |
| 카메라 / LiDAR | 패널·오염 영상과 접근 거리 측정 |
| 지상 펌프 / 호스 / 솔레노이드 / 노즐 | 지상 급수와 선택 분사 |

Panel V4로 전체 영상에서 패널을 찾고, 검출한 패널 영역에 Dirt V3를 적용해 오염 위치를 추출합니다. 추론 결과는 임무 컴퓨터로 전달되어 접근·정렬·분사 판단에 활용됩니다.

## 구현과 시험

팀 최종보고서에는 패널 인식과 경로 생성, 계획 경로 비행 후 귀환·자동 착륙을 완료했다고 기록되어 있습니다. 분사 명령과 장치도 동작했으나, 최종 비행에서 목표 오염물을 정확히 타격하지 못해 정밀 조준 개선이 남았습니다.

모델의 인식 성능과 실제 세척 성능을 구분하고, 통신 지연·카메라와 노즐의 위치 보정·분사장치 고정 문제를 후속 개선 과제로 정리하고 있습니다.
