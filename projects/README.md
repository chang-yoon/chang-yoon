# 프로젝트

프로젝트별 목표, 역할, 문제 해결 과정과 결과를 정리하는 공간입니다. 현재 자료를 정리하고 있으며, 확인을 마친 프로젝트부터 추가합니다.

각 프로젝트에는 목표·기간·팀 규모, 직접 수행한 일, 기술의 사용 목적, 문제 해결 과정, 결과·측정 조건, 한계와 배운 점을 담습니다.

팀 프로젝트는 원본 저장소와 개인 기여 문서를 함께 연결합니다. 코드는 본인 기여와 공개 가능 범위를 확인한 뒤 프로젝트별 저장소에서 제공합니다.
