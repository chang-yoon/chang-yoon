# 차량 현가장치 진동 모델링과 주파수응답 분석

**수업 공통 과제 · 2025년 2학기 · 3학년 진동공학 · 3인 팀 보고서**

수강생에게 동일하게 주어진 문제로 진동 모델링과 MATLAB의 기초를 익힌 수업 과제입니다. 차량의 차체와 휠을 2자유도로 표현해 공진 특성을 살펴보고, 1자유도 모델에서 강성과 감쇠에 따른 응답 변화를 비교했습니다.

## 목표와 수행 과정

차체와 휠의 진동이 서로 다른 주파수에서 크게 나타나는 이유를 파악하고, 설계 변수에 따라 공진 위치와 진폭이 어떻게 달라지는지 이해하는 과제였습니다.

1. Quarter-car 모델의 자유물체도와 운동방정식을 작성했습니다.
2. 질량·감쇠·강성 행렬과 임피던스 행렬을 구성했습니다.
3. 노면 변위에 대한 차체·휠 변위의 주파수응답함수(FRF)를 구하고 MATLAB 그래프와 이론 고유진동수를 비교했습니다.
4. 1자유도 기초가진 모델에서 상대변위의 진폭과 위상을 분석했습니다.
5. 강성 0.5·1·1.5배, 감쇠 0.5·1·2배 조건을 비교하고 결과를 보고서로 정리했습니다.

## 주요 결과

| 분석 | 보고서에서 확인한 결과 |
| --- | --- |
| 2자유도 비감쇠 고유진동수 | 약 1.18 Hz, 11.08 Hz |
| 감쇠를 포함한 주파수응답 | 차체의 주요 피크 약 1.15 Hz, 휠의 고주파 피크 약 10.71 Hz |
| 1자유도 기본 조건 | 노면 진폭 0.01 m에서 상대변위 그래프 피크 약 0.0317 m, 약 11.3 Hz |
| 강성 비교 | 강성을 낮추면 피크가 저주파 쪽으로, 높이면 고주파 쪽으로 이동 |
| 감쇠 비교 | 감쇠를 높이면 공진 부근의 상대변위 피크가 낮아지고 곡선이 완만해짐 |

이는 보고서의 수식·코드 이미지·그래프에 기반한 수치해석 결과입니다. 실차의 승차감이나 진동 저감 성능을 측정한 값은 아닙니다.

## 본인 참여와 배운 점

팀 프로젝트에 참여해 보고서를 작성했습니다. 보고서에는 3명이 기재되어 있으며, 세부 모델링·코드의 개인별 분담은 별도로 기록되어 있지 않습니다.

이 경험은 자유물체도를 행렬식과 계산 모델로 연결하고, 그래프의 피크를 물리적 현상으로 해석하는 기초를 다룬 사례입니다. 강성에 따른 공진 위치 변화와 감쇠에 따른 진폭 변화를 함께 비교하며 설계 변수의 역할을 정리했습니다.

## 지원 직무 연결

- **기계설계·해석:** 운동방정식, 동특성 및 설계 변수 비교
- **차량·부품 연구개발:** 현가장치의 차체·휠 응답과 공진 특성 이해
- **시험·평가:** 이론 고유진동수와 수치해석 그래프를 구분해 해석하는 경험
