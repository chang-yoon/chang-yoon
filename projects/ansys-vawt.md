# ANSYS Fluent 기반 수직축 풍력터빈 익형 비교

**2026년 1학기 기계공학특수연구 · 4인 팀 프로젝트**

H-Type 수직축 풍력터빈에 적용할 NACA 0012·0015·0018 익형을 비교했습니다. ANSYS Fluent로 회전 유동을 해석하고, MODDE에서 익형과 풍속에 따른 성능을 비교하여 팀 발표에서 **NACA 0015를 설계안으로 선정**했습니다.

## 목표

도심 풍속 조건을 고려해 블레이드의 압력·속도·와류와 토크·출력계수를 살펴보고, 기동성과 발전 효율을 함께 고려한 익형을 선정하는 것이 목표였습니다.

## 내가 수행한 일

팀원들과 프로젝트 전 과정을 공동 수행했습니다.

- NACA 익형과 회전 유역의 2D 모델 구성
- 경계조건·격자·회전 해석 조건 설정
- 유동장과 토크·출력계수 결과 비교
- MODDE를 활용한 조건별 분석과 설계안 선정
- 결과 해석과 발표자료 정리

세부 단계는 [공동 수행 내용](../docs/ansys-vawt/contributions.md)에 정리했습니다.

## 해석 방법

| 항목 | 발표자료 기준 |
| --- | --- |
| 도구 | ANSYS Fluent, MODDE |
| 비교 익형 | NACA 0012 / 0015 / 0018 |
| 모델 | 2D 회전 유동 |
| 회전 해석 | Sliding Mesh 기반 비정상 해석 |
| 난류 모델 | k–ω SST |
| 유입 풍속 | 2 / 7 / 12 m/s |
| 회전속도 | 60 rpm |
| 주요 검토 결과 | 압력·속도·와류, 토크계수·출력계수 |

[해석 과정과 조건](../docs/ansys-vawt/methodology.md)

## 설계 판단

익형 두께에 따른 압력 분포와 유동 박리, 토크와 출력 특성을 함께 비교했습니다. 발표자료에서는 NACA 0015가 기동성과 출력의 균형에 적합하다고 판단해 설계안으로 제시했습니다. MODDE의 Sweet Spot Plot으로 풍속·익형 조건에 따른 목표 충족 영역도 살펴봤습니다.

이 선정은 수업 프로젝트에서 다룬 조건과 분석에 대한 결론입니다. 모든 풍속·운전 조건에서의 최적 성능이나 실물 발전량 개선을 입증한 결과로 확대하지 않습니다.

## 결과와 검증 범위

2D 해석 모델, 유동장 비교, MODDE 분석과 익형 선정 결과를 발표자료로 정리했습니다.

출력계수와 검증 오차는 자료 간 수치·조건 대조가 남아 있어 정량성과로 제시하지 않았습니다. 실물 풍동 시험, 독립적인 격자·시간간격 민감도 검증과 실제 시동 성능은 현재 정리한 자료만으로 완료를 확인하지 못했습니다.

## 취업 역량 연결

- **설계·CAE:** 형상과 해석 조건을 설정하고 결과를 설계안 선정에 연결
- **연구개발:** 여러 설계변수와 성능 기준을 비교하는 분석 과정
- **검증:** 해석 결과의 조건·계산 기준·한계를 구분하는 문서화
