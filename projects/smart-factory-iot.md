# 센서·MQTT·Node-RED 기반 스마트팩토리 IoT 실습

**2026년 1학기 기계공학특수연구 · 개인과제 2개와 6인 팀과제 4개**

센서값을 대시보드로 전달하고, 화면에서 내린 명령을 실제 출력 장치에 연결하는 실습을 단계적으로 수행했습니다. 최종 팀과제에서는 온도 측정과 마스크 영상분류를 결합해 출입 상태를 판정하고 팬·경고 LED로 표현했습니다.

## 수행 과정

| 구분 | 과제 내용 | 확인한 산출물 |
| --- | --- | --- |
| 개인 #1 | DHT22 온습도 데이터의 MQTT 전송과 Node-RED 표시 | 프로그램·플로·게이지 화면 |
| 개인 #2 | GPIO에서 트랜지스터·릴레이를 거쳐 팬을 구동하는 원리 설명 | 신호 전달 과정 설명서 |
| 팀 #1 | MQTT 명령에 따른 ESP8266 팬 ON/OFF | 코드·플로·회로 및 동작 비교 사진 |
| 팀 #2 | BMP180 온도 웹 모니터링과 임계값에 따른 LED 제어 | 코드·웹 화면·회로 사진 |
| 팀 #3 | 온도 데이터 전송과 팬 제어·상태 메시지 연계 | 코드·Node-RED 화면·회로 사진 |
| 팀 #4 | 마스크 분류와 온도 조건을 결합한 출입 상태 판정 | 코드·플로·세 가지 시나리오의 화면과 사진 |

개인과제는 직접 제출한 학습·구현 기록이며, 팀과제는 4조 구성원으로 참여한 공동 산출물입니다. 팀과제 전체를 개인 단독 개발로 표현하지 않습니다.

## 기술 구성

- **제어 보드:** ESP8266, Arduino 환경의 프로그램
- **센서:** 개인과제의 DHT22 온습도, 팀과제의 BMP180 온도 측정
- **통신:** Wi-Fi, MQTT 발행·구독, ESP8266 HTTP 서버
- **화면·판단:** Node-RED Dashboard, Teachable Machine 기반 마스크 분류 연계
- **출력:** GPIO, 트랜지스터·릴레이 회로, 팬, 경고 LED

## 최종 실습의 동작

카메라 영상의 마스크 분류 결과와 센서 온도를 Node-RED에서 결합했습니다. 보고서는 마스크 착용과 온도 조건을 모두 충족하면 출입 가능, 하나라도 미충족하면 출입 불가로 판정하는 구조를 설명합니다.

팬은 출입 허가를 나타내는 실습용 출력으로 사용했습니다. 실제 출입문이나 공장 설비를 운용한 프로젝트로 확대하지 않습니다. 보고서의 온도값 역시 실습 센서의 측정값으로 기록합니다.

## 결과와 검증 범위

팀과제 #4에는 정상 조건, 온도 초과, 마스크 미착용에 대한 판정 화면과 회로 사진이 포함되어 있습니다. 센서 입력·영상분류·조건 판단·메시지 전송·출력 장치를 연결한 실습 과정이 확인됩니다.

자료의 코드와 화면을 검토했으며 현재 장치에서 다시 실행한 것은 아닙니다. 분류 정확도, 통신 지연, 장시간 안정성에 대한 정량성과는 별도 측정 근거가 없어 제시하지 않습니다.

최종 제출자료의 판정 기준은 28℃입니다. 실습에서 센서 온도를 36℃까지 올리기 어려워 기준을 낮춰 시험한 것으로 정리했습니다. 이 값은 시나리오를 재현하기 위한 실습 설정입니다.

## 내 경험과 직무 연결

개인과제에서 MQTT 데이터 전달과 팬 구동 회로의 역할을 정리하고, 팀과제에서는 센서·통신·화면·구동부를 연결하는 실습에 참여했습니다.

- **생산기술·자동화:** 센서 입력을 조건 판단과 출력 동작으로 연결하는 구조
- **설비·제어:** 제어 신호와 부하 구동 회로의 역할 구분
- **시스템 통합:** MQTT 데이터·명령·상태 메시지와 대시보드 연계
