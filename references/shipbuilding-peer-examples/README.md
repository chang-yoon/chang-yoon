# 조선해양공학 선배 자기소개서 참고

현대미포 채용연계형 인턴 자기소개서를 읽고 작성 구조와 참고할 점을 정리한 분석 자료입니다. 본인의 지원서와 구분하며, 원문 파일과 개인정보는 포함하지 않습니다.

- 자료: 현대미포 채용연계형 인턴 최종 자기소개서
- 작성자 배경: 조선해양공학 전공 선배, 앞서 제공된 자동차 기업 지원자료 작성자와 다른 사람
- 지원 분야: 선박설계, 기본설계 선호
- 전형 결과: 최종합격이라고 사용자에게 전달받음
- 채용 연도: 제공 자료만으로 확인되지 않음
- 합격 범위: 채용연계형 인턴 선발 최종합격 사례로 기록. 인턴 종료 후 정규직 전환 여부는 미확인
- 읽은 범위: DOCX 본문 자기소개서 4개 문항. 문항별 최대 500자 표기
- 분석일: 2026-09-21

## 현재 회사와 자료의 당시 명칭

HD현대미포는 2025년 12월 1일을 합병기일로 HD현대중공업에 흡수합병되었습니다. 합병존속회사는 HD현대중공업, 합병소멸회사는 HD현대미포입니다. 2026-09-21 기준 이 자료는 **구 현대미포 채용연계형 인턴 합격 사례 — 현재 HD현대중공업에 통합**으로 분류합니다.

자료의 제목과 당시 지원 회사명인 ‘현대미포’는 그대로 유지합니다. 이를 현재 HD현대중공업 채용의 합격 사례로 바꾸거나, 선배의 합격 시점·소속 변경·정규직 전환 여부를 합병 사실만으로 추정하지 않습니다. 향후 HD현대중공업 지원 시 작성법 참고자료로 활용하되, 직무·조직·채용요건은 해당 시점 공고를 확인합니다.

출처: [HD현대중공업 증권발행실적보고서(합병), 2025-12-01](https://kind.krx.co.kr/external/2025/12/01/000492/20251201001014/10810.htm), [HD현대중공업 공식 합병 승인 안내](https://naval-special.hhi.co.kr/ko/media01_view/115).

합격 사실은 사용자 설명에 기반하며 합격 통지서를 별도로 검증한 것은 아닙니다. 특정 문장이나 소재가 합격의 원인이었다고 단정하지 않습니다. 당시 직무 설명을 현재 채용공고의 요구사항으로 취급하지 않습니다.

## 문항별 구성과 평가

| 문항 | 구성 | 배울 점 | 그대로 따라 쓰지 않을 점 |
| --- | --- | --- | --- |
| 선호 직무 | 기본설계 선택 이유 → 직무 역할과 기술 업무 설명 | 넓은 설계 분야 안에서 하고 싶은 일을 구체적으로 선택 | 본인 경험보다 직무 설명의 비중이 큼. 지원동기 문항이라면 개인적 선택 근거를 늘릴 것 |
| 필요한 역량과 준비 | 전공 해석 과제 → 모형선 제작·설계 변경 | 과목 학습을 실제 설계·제작 경험으로 연결. 사용 조건의 문제와 변경 이유를 제시 | 역량 세 가지를 선언해도 각 역량의 근거가 모두 충분히 드러나는 것은 아님. 기술 용어 나열을 줄일 것 |
| 인상 깊은 경험 | 소통 필요성 인식 → 낯선 환경에 도전 → 자신감·관점 변화 | 약점을 밝힌 뒤 실행과 변화로 이어짐 | 구체적인 대화·행동 사례가 적어 일부 결론이 추상적. 해외 경험 자체를 성장의 증거로 삼지 말 것 |
| 갈등 해결 | 운반 부담에 대한 불만 → 운반 보조 수단 제작 → 제작 책임·작업 분담 조율 | 갈등이 생긴 작업 조건을 바꾸고, 책임·일정·분담을 정하는 행동으로 연결 | 제작 완료 후 갈등 감소나 실제 사용 결과가 명확하지 않음. 확인되지 않은 결과를 보충하지 말 것 |

## 특히 참고할 갈등 문항의 구조

원문의 갈등은 기술적 의견 충돌보다 반복되는 작업 부담과 공정한 분담의 문제입니다. 운반 과정의 불편을 발견하고 보조 수단을 만들기로 했지만, 그 제작을 누가 맡을지 다시 조율해야 했다는 점에서 상황이 구체적입니다.

참고할 흐름은 다음과 같습니다.

1. 불만이 발생한 실제 작업과 부담을 설명한다.
2. 상대의 성격이 아니라 갈등을 만드는 조건을 찾는다.
3. 작업 방식의 변경과 역할 조정을 구분한다.
4. 본인이 맡은 책임, 일정 협의, 분담 행동을 적는다.
5. 실제 확인된 결과까지만 말한다.

이 구조를 참고하되, 선배의 운반·카트 제작·리더십 경험을 본인의 경험으로 옮기지 않습니다. 본인의 협업 사례에서도 누가 어떤 의견을 냈고 어떤 행동을 했는지는 별도 사실 확인이 필요합니다.

## 말투와 용어 사용

- 직무를 선택한 이유와 필요한 역량을 먼저 밝히는 문장 구조는 참고할 수 있습니다.
- 조정·비교·설계 변경·일정 수립·작업 분담처럼 행동과 대상을 연결하면 역할이 드러납니다.
- 직무 전문성은 용어의 수보다 그 용어가 설명하는 판단과 행동으로 보여줍니다.
- 원문에 있는 선형 변환 기법, 설계 변수, 선박 규모는 선박설계 지원 맥락의 정보입니다. 본인의 발전/공무·생산기술 지원서에 그대로 사용하지 않습니다.
- 본인 자소서에서는 별도 요청이나 문항상 필요가 없으면 익형 번호·세부 변수명은 생략합니다. 문제, 비교 기준, 행동, 결과를 중심으로 씁니다.
- 리더십·전문성·끈기를 여러 번 선언하는 대신 실제 조율과 수정 행동을 제시합니다.
- 합격 자료에도 오탈자와 추상적인 마무리가 있습니다. 원문 표현 전체를 모범 답안으로 취급하지 않습니다.

## 본인 지원서에 적용할 점

| 본인 소재 | 활용할 구조 |
| --- | --- |
| 드론 통합 임무 구현 | 목표 동작 → 실제 연결 문제 → 담당자 간 검토와 수정 → 확인된 구현 범위 |
| CFD 프로젝트 | 사용 조건 → 비교 기준 → 설계안 선택 근거. 세부 익형 번호는 기본적으로 생략 |
| 군 조교 | 처음의 전달 어려움 → 피드백 → 실제 연습과 변화 → 업무 설명에 활용 |
| 갈등 문항 | 경험의 크기보다 구체적인 의견 차이·본인의 행동·확인된 결과를 우선 |

이 자료에서 가장 유용한 점은 특별한 사건을 과장하는 대신, 실제 활동에서 생긴 불편과 조율 과정을 설명하는 방식입니다. 앞으로 작성할 때 이 분석을 다시 읽어 참고하며, 문서 저장이 모델 자체의 학습이나 모든 대화에서의 자동 기억을 의미하지는 않습니다.
