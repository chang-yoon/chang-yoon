# 기계공학 선배 지원자료 분석

개인정보와 원문 전문을 제외하고, 사용자가 제공한 선배 지원자료 세 건의 작성 구조와 활용 원칙을 정리했습니다. 본인의 지원 이력과 혼동하지 않도록 applications와 분리합니다.

## 자료와 전형 결과

| 기업 | 자료상 직무 | 사용자에게 전달받은 결과 | 읽은 범위 |
| --- | --- | --- | --- |
| 현대자동차 | 차량 프로젝트 관리 | 최종합격 | 자기소개서·전공과목·프로젝트·학내외활동 |
| 기아 | 구매/부품개발 - 선행부품개발 | 1차 면접 탈락 | 자기소개서·프로젝트·학내외활동 |
| GM | AVD & SVI | 전화 면접 합격 후 지원 중단 | 이력서와 자기소개서 |

결과는 사용자의 설명이며 기업 통지서를 검증한 결과가 아닙니다. 원문에는 과거 활동과 입사 희망 시점이 포함되어 있으나 정확한 채용 회차·제출 최종본 여부는 확인되지 않았습니다. 최신 공고 또는 모든 합격자를 대표하는 자료가 아닙니다. 현대차 최종합격을 특정 문장의 효과로 단정하거나 기아 면접 탈락을 자소서 결함으로 해석하지 않습니다. GM은 최종합격 사례가 아닙니다.

## 다음 지원서 작성 때

- 먼저 해당 기업의 실제 모집공고, 직무기술서, 문항 및 글자 제한을 새로 확인합니다. 기아·GM의 모집 시작 여부와 미래 일정을 이 자료만으로 판단하지 않습니다.
- 선배의 문장 구조와 판단 방식만 참고하고, 경험·역할·성과 수치는 본인의 사실로 대체합니다.
- 자료의 기술 용어는 이해한 경우에만 사용합니다. 과거의 기업 전략·슬로건·직무 약어는 현재 공고와 대조합니다.
- 분석문은 원문 내용의 요약과 작성상 판단입니다. 선배의 학점·연락처·주소·생년월일·서명·자격번호와 PDF 원문은 공개하지 않습니다.
- 지속적으로 참고하는 방법은 이 문서를 다시 읽는 것입니다. 모델 자체가 별도로 학습되거나 모든 미래 대화에서 자동으로 기억된다는 의미는 아닙니다.
