# 팀 참여 범위

2025년 2학기 기계설계의 3인 팀 프로젝트에 참여했습니다. 보고서는 회전목마 구동계의 기구 배치, 기어 계산, 부하 산정, 모터 선정안과 설계 고찰을 담고 있습니다.

현재 자료에는 개인별 작업 분담이 없습니다. 전체 산출물은 팀 설계 경험으로 소개하며, CAD 모델 전체 제작이나 특정 계산·모터 선정을 혼자 담당했다고 단정하지 않습니다.

취업 자료에는 기계요소를 연결해 구동계를 검토한 팀 프로젝트 경험으로 활용합니다. 구체적인 개인 담당 내용이 확인되면 기여를 보완할 수 있습니다. 2026년 9월에 발견한 계산 검토 사항은 당시 직접 발견·해결한 경험으로 소급하지 않습니다.
