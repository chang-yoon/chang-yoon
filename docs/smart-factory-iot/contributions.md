# 개인·팀 과제 구분

## 개인 제출

| 과제 | 수행 기록 |
| --- | --- |
| 개인 #1 | DHT22 온습도 데이터를 MQTT로 보내고 Node-RED 게이지에 표시한 코드·화면 |
| 개인 #2 | Node-RED 명령부터 GPIO·트랜지스터·릴레이·팬까지 신호 전달 원리 설명 |

개인 #1은 화면과 코드로 확인한 실습 기록입니다. 해당 자료만으로 별도 실물 센서 정확도 시험까지 수행했다고 설명하지 않습니다.

## 팀 수행

4조는 6인 팀이며, 본인은 과제 #1~#4의 구성원으로 참여했습니다. 팀 산출물은 팬 원격 제어, 온도 웹 모니터링, MQTT 온도·팬 연계, 영상분류와 온도 기반 판정으로 확장됩니다.

현재 자료에는 개인별 작성 파일이나 세부 업무 분담이 명시되어 있지 않습니다. 따라서 팀의 구현 내용과 개인이 단독 수행한 내용을 동일하게 취급하지 않습니다.

## 경험을 설명하는 방향

- 개인과제에서 학습한 센서 데이터 전달과 구동 회로 원리
- 팀 실습에서 센서·통신·판단·출력을 연결한 과정
- 화면 상태와 실제 회로 출력을 함께 확인한 제출 기록
- 설정값과 실측 성능, 명령 상태와 물리적 피드백의 구분
