# 차량 진동 모델과 해석 범위

## 2자유도 Quarter-car 모델

보고서 Part I의 입력값입니다.

| 변수 | 값 |
| --- | ---: |
| 차체 질량 ms | 300 kg |
| 비현가 질량 mu | 45 kg |
| 현가 강성 ks | 18,000 N/m |
| 타이어 강성 kt | 200,000 N/m |
| 현가 감쇠 cs | 1,000 N·s/m |

좌표를 `q = [xs, xu]ᵀ`, 노면 입력을 `y`로 두면 `M q̈ + C q̇ + K q = [0, kt·y]ᵀ`로 표현합니다.

```text
M = [ms,  0 ]    C = [ cs, -cs]    K = [ ks,   -ks  ]
    [ 0, mu ]        [-cs,  cs]        [-ks, ks + kt]

Z(ω) = K - ω²M + iωC
Hs = Xs/Y = -kt·Z12 / det(Z)
Hu = Xu/Y =  kt·Z11 / det(Z)
```

보고서는 비감쇠 고유진동수를 약 1.18·11.08 Hz로 계산하고, 감쇠를 포함한 FRF 그래프의 차체 피크 약 1.15 Hz와 휠 피크 약 10.71 Hz를 비교했습니다. 고유진동수와 응답 피크 주파수는 구분해 기록합니다.

## 1자유도 상대변위 모델

보고서 Part II에서는 `m = 45 kg`, `k = 218,000 N/m`, `c = 1,000 N·s/m`를 사용했습니다. 기초와 질량 사이의 상대변위 `z = x - y`에 대해 다음 일반 기초가진 모델을 계산했습니다.

```text
m z̈ + c ż + k z = -m ÿ
H(ω) = Z/Y = mω² / (k - mω² + i cω)
상대변위 진폭 = 0.01 × |H(ω)| [m]
```

코드 이미지에서는 0~20 Hz를 0.01 Hz 간격으로 계산하고 위상에 `atan2`를 사용합니다. 그래프의 세로축은 입력 진폭을 곱한 상대변위[m]이며 무차원 전달률 자체와 구분합니다. 기본 조건의 그래프 표시는 약 11.3 Hz, 0.0317049 m입니다.

강성 비교는 109,000·218,000·327,000 N/m, 감쇠 비교는 500·1,000·2,000 N·s/m입니다. 이는 변수 영향 비교이며, 후속 설계 항목의 감쇠 ±5% 제한을 만족한 최종 설계값은 아닙니다.

## 모델을 적용할 때의 범위

보고서는 차체를 고정점으로 근사해 `ks + kt`를 설명한 후, 스프링·댐퍼가 같은 이동 기초에 연결된 일반 1자유도 식을 사용했습니다. 두 모델의 가진 전달 경로는 동일하지 않습니다. 차체를 실제 고정점으로 놓은 원래 모델은 `mu ẍu + cs ẋu + (ks + kt)xu = kt y`가 되므로, 이를 원래 Quarter-car 모델과 정확히 동등한 축약으로 표현하지 않습니다.

감쇠 변화는 피크 높이뿐 아니라 피크 위치에도 영향을 줄 수 있습니다. 보고서의 비교 결과는 감쇠 증가에 따른 공진 부근 진폭 감소를 중심으로 설명합니다.
