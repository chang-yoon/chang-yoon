# 참여 범위

**2025년 2학기 진동공학 · 보고서상 3인 팀**

본인은 진동공학 프로젝트에 참여하고 결과 보고서를 작성했습니다. 보고서는 2자유도 모델링, 임피던스와 FRF 유도, MATLAB 응답 그래프, 1자유도 강성·감쇠 비교를 담고 있습니다.

보고서에 기재된 전체 분석은 팀 프로젝트 산출물로 소개합니다. 개인별 수식 유도·코드 작성 분담이 명시되지 않아, MATLAB 코드 전체를 혼자 개발했다거나 모든 해석을 단독 수행했다고 표현하지 않습니다.

취업 자료의 활용 초점은 진동계 모델링을 이해하고 이론과 그래프를 연결해 설명한 경험, 보고서 작성 경험입니다. 담당 부분이 추가로 확인되면 구체적인 작업과 문제 해결 사례를 보완합니다.
