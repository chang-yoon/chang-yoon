# 해석 과정과 조건

[ANSYS 풍력터빈 프로젝트](../../projects/ansys-vawt.md)의 팀 수행 과정을 정리한 문서입니다. 최종 산출물로 지정한 발표 PPT의 3·6~18장을 기준으로 작성했습니다.

## 작업 흐름

```mermaid
flowchart LR
    A["NACA 익형 비교 범위 설정"] --> B["2D 형상·회전 유역 구성"]
    B --> C["격자·경계조건 설정"]
    C --> D["Fluent 비정상 회전 유동 해석"]
    D --> E["압력·속도·와류 및 계수 비교"]
    E --> F["MODDE 조건별 분석"]
    F --> G["발표 설계안 NACA 0015 선정"]
```

## 모델과 경계조건

- NACA 0012·0015·0018을 비교 대상으로 설정했습니다.
- 2D 모델을 사용하고 원거리·허브·블레이드 영역을 구분했습니다.
- 원거리 영역은 외부 경계가 터빈 주변 유동에 미치는 영향을 고려해 구성했습니다.
- 블레이드 주변 Inflation 설정은 발표자료에 최대 30층, 성장률 1.2로 기재되어 있습니다.
- 유입 풍속은 2·7·12 m/s, 회전속도는 60 rpm으로 설정했습니다.
- 입구 난류 강도 5%, 점성비 1, 출구 pressure outlet, 블레이드 no-slip 조건을 사용한 것으로 발표자료에 기록되어 있습니다.

치수·물성·압력 기준의 완전한 재현 설정은 원본 해석 파일과 대조가 필요합니다. 이 문서는 실행 가능한 Fluent 설정 파일을 대신하지 않습니다.

## 수치해석

Sliding Mesh를 이용한 비정상 회전 해석, k–ω SST 난류 모델, 비압축성·등온 가정을 적용했습니다. 계산 잔차를 검토하고 압력·속도·와류 분포를 비교했습니다.

발표자료의 잔차 표를 격자 독립성이나 주기별 토크 수렴의 별도 검증으로 취급하지 않습니다.

## MODDE 분석

최종 발표에서 다룬 독립변수는 익형 두께와 유입 풍속이며, 응답변수는 토크계수와 출력계수입니다. 17장의 Sweet Spot Plot은 풍속과 익형 조건에 따라 두 응답의 기준을 충족하는 영역을 보여줍니다.

초기 주제 문서에 포함된 Camber·피치각까지 실제 최종 분석에서 모두 변화시켰다고 확대하지 않습니다. 반응모델의 적합도와 재현 가능한 입력 데이터는 추가 대조가 필요합니다.

## 설계안 선정

발표에서는 익형별 압력·유동 특성과 토크·출력의 균형을 검토해 NACA 0015를 선택했습니다. 수치가 달리 기재된 부분은 정량성과에서 제외하고, 비교 방법과 선정 과정 중심으로 기록합니다.
