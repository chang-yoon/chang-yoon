# 공동 수행 내용

**기계공학특수연구 · 2026년 1학기 · 4인 팀**

프로젝트 전 과정을 팀원들과 공동 수행했습니다. 아래는 참여한 단계와 해당 단계에서 다룬 내용입니다.

| 단계 | 공동 수행 내용 |
| --- | --- |
| 문제 정의 | 수직축 풍력터빈의 익형 비교 목표와 성능 기준 정리 |
| 모델링 | NACA 익형의 2D 형상과 회전 유역 구성 |
| 해석 준비 | 격자, 경계조건, 난류 모델과 회전 해석 설정 |
| 결과 분석 | 압력·속도·와류 및 토크·출력계수 비교 |
| 설계안 선정 | MODDE 분석과 익형 간 특성 비교 |
| 문서화 | 해석 과정·결과와 최종 설계안 발표 정리 |

이 참여 범위는 실제 작업을 함께 진행했다는 본인의 설명에 따라 정리했습니다. 계획 단계 역할표를 개별 기능의 단독 담당 근거로 사용하지 않습니다.

## 설명할 수 있는 경험

- 2D 모델을 선택하고 고정·회전 영역을 구성한 과정
- 경계조건과 격자 설정을 정리한 과정
- 서로 다른 익형의 유동장과 성능 지표를 비교한 과정
- MODDE 분석을 익형 선정 논의에 연결한 과정
- 수치와 계산 조건의 일관성을 확인하며 결과를 문서화한 과정
